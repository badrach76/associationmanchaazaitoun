# منصة جمعية منشأ منتوجات الزيتون بإقليم قلعة السراغنة

واجهة أولية متعددة الأقسام مبنية بـ HTML/CSS/JavaScript، قابلة للنشر على Vercel وربطها بـ Supabase.

## الملفات
- `index.html`: صفحات المنصة وأقسامها.
- `styles.css`: الهوية البصرية والتجاوب مع الهاتف والحاسوب.
- `app.js`: نماذج الانخراط والتواصل، الدخول، عرض الأخبار والأنشطة ولوحة الإدارة.
- `supabase-schema.sql`: الجداول وسياسات الحماية الأولية.

## التشغيل المحلي
افتح `index.html` في المتصفح. في وضع المعاينة، تظهر الواجهة لكن إرسال الطلبات وتسجيل الدخول الحقيقي يتطلبان ربط Supabase.

## ربط Supabase
1. أنشئ مشروعاً جديداً في Supabase.
2. افتح SQL Editor ونفّذ محتوى `supabase-schema.sql`.
3. افتح `app.js` وضع رابط المشروع ومفتاح `anon` في `SUPABASE_URL` و`SUPABASE_ANON_KEY`.
4. أنشئ حساب المسؤول من Authentication.
5. بعد إنشاء الحساب، نفّذ استعلام ترقية الدور الموجود في نهاية ملف SQL مع بريد المسؤول.
6. أنشئ حسابات المنخرطين وفق آلية التحقق التي تعتمدها الجمعية.

## النشر على Vercel
ارفع الملفات إلى مستودع GitHub ثم اربط المستودع بمشروع Vercel. لا تضع مفاتيح `service_role` داخل ملفات الواجهة؛ استخدم مفتاح `anon` فقط مع سياسات RLS.

## ملاحظات قبل الإطلاق
- يجب استكمال بيانات المقر والهاتف والبريد الرسمي.
- يجب اعتماد الشعار الرسمي للجمعية.
- يجب مراجعة النظام الأساسي للجمعية لتحديد شروط العضوية والوثائق المطلوبة ورسوم الانخراط إن وجدت.
- هذه نسخة تأسيسية قابلة للتطوير، وليست بعدُ نظاماً إنتاجياً مكتملاً؛ يلزم اختبار الصلاحيات، وإجراءات الموافقة على العضوية، واستعادة كلمة المرور، والوثائق وبطاقات العضوية قبل الإطلاق العام.
